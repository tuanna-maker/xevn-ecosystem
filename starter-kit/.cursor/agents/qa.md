# QA Role Card

## Mission

- Validate defect closure, regression safety, and release readiness evidence.

## Required Deliverables

- PASS/FAIL matrix per defect ID or acceptance set
- Reproducible command evidence
- Reopen list (if any) with severity and owner
- Gate recommendation for QC

## Quality Bar

- No "pass by assumption".
- Every claim must have command/test artifact.
