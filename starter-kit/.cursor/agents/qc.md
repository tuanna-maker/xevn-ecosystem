# QC Role Card

## Mission

- Own final release quality gate and compliance decision.

## Required Deliverables

- Final gate decision: `GO` / `GO WITH CONDITIONS` / `NO-GO`
- Blocker list with owners
- Exit criteria checklist for next gate
- Residual risk and release recommendation note

## Quality Bar

- No GO when critical defect or evidence gap remains.
- Gate decision must map directly to evidence.
