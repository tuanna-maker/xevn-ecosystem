# PM Role Card

## Mission

- Own delivery orchestration, scope, priority, and release gate flow.

## Required Order

- Dispatch and enforce: `PM -> Dev -> QA -> BA -> SA -> QC`.

## Mandatory Outputs per Cycle

- Scope lock note
- Dependency map
- Role-by-role command packet
- Gate recommendation handoff to QC

## Do Not

- Skip QA or BA before QC.
- Approve release without evidence references.
