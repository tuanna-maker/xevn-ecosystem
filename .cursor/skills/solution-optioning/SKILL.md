# Solution Optioning

## Use when
- Architecture/implementation direction is not obvious.
- Decision has meaningful cost, risk, or long-term impact.

## Workflow
1. Define decision context and constraints.
2. Generate at least 3 credible options.
3. Score options using weighted criteria:
   - business value
   - engineering complexity
   - delivery time
   - security/reliability risk
   - long-term maintainability
4. Document failure modes and mitigations per option.
5. Recommend one option with explicit assumptions.
6. Define post-decision validation checkpoints.
