# Product Discovery

## Use when
- New module/program definition.
- Scope or roadmap is unclear.
- Team needs evidence before committing implementation.

## Workflow
1. Frame the problem: user segment, pain, business impact.
2. Define measurable outcomes:
   - North star metric
   - 2-4 leading indicators
   - guardrails (quality/cost/risk)
3. Build hypothesis list and validation plan.
4. Prioritize opportunities by value, confidence, and effort.
5. Propose phased scope (MVP -> scale).
