# Business Analysis Pack

## Use when
- Turning business intent into executable delivery artifacts.
- Preparing handoff from BA to SA/Dev/QA.
- **Tài liệu gửi khách (BRD/SRS HTML):** đọc thêm `.cursor/skills/client-delivery-docs/SKILL.md` — không ghi meta prompt vào deliverable.

## Workflow
1. Capture actors and use-case catalog.
2. Write flow variants:
   - Happy path
   - Alternate paths
   - Exception/error paths
3. Build business rules table (`condition -> action -> outcome`).
4. Build validation matrix (field, rule, message, error code).
5. Define acceptance criteria and evidence expectations.
6. Complete requirement-to-test traceability rows.
