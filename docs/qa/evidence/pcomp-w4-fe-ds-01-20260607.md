## Key findings

| Finding | Impact |
|---------|--------|
| HRM embed renders all `rem` classes **~12.5% smaller** than nominal Tailwind docs | `text-base` = **14px** not 16px; explains web/mobile number drift vs `tokens.ts` |
| `tokens.ts` fontSize matches **portal @100%** (12,14,16,18,20,24,30) | Parity test correct for colors/radius; typography numbers are **not** HRM effective px |
| shadcn defaults cluster at `text-sm` (~12px) and `text-xs` (~10.5px) | Below mobile DS min **13pt footnote** / **12pt caption** |
| Mobile DS §1 targets **17pt body**; current `fontSize.base` = **16** | G-DS-01 — MOB-UX-03 bump |
| Semantic tokens (`largeTitle`, `footnote`, `tabLabel`, …) absent from `tokens.ts` | G-DS-03 — Dev-Mobile extends typography export |
| Web `Button text-sm` vs mobile `PrimaryButton 17pt` | G-DS-05 — **accepted** platform divergence per §0 |
