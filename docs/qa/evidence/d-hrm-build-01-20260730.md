## Root cause (confirmed)

TypeScript **incremental** `nest build` does **not** re-emit deleted/missing `dist/` files when `tsconfig.build.tsbuildinfo` exists and source unchanged.

Repro:

```powershell
cd apps/api/hrm-api
Remove-Item dist/common/http-exception.filter.js -Force
Remove-Item dist/spreadsheet/spreadsheet-template.service.js -Force
pnpm exec nest build
Test-Path dist/common/http-exception.filter.js   # False — still missing
```

Partial dist after watch wipe / concurrent build / manual delete → runtime crash even though `nest build` exit 0.

## Fix (config + guard only — no API logic)

| File | Change |
|------|--------|
| `scripts/verify-dist.mjs` | **ADD** — spine module gate (`DIST_SPINE` 6 files); exit 1 if missing |
| `scripts/ensure-dist.mjs` | **FIX** — skip futile incremental `nest build`; go straight to `build:clean` when spine missing |
| `package.json` | `postbuild` → verify-dist; `build:clean` → verify after nest build |

Spine modules checked:

- `dist/main.js`
- `dist/app.module.js`
- `dist/common/http-exception.filter.js`
- `dist/platform/platform-runtime.js`
- `dist/spreadsheet/spreadsheet-template.service.js`
- `dist/spreadsheet/spreadsheet.module.js`
