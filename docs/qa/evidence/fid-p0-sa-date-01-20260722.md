## 1. Packet — «spec says / code does / DB stores»

### 1.1 Create attendance sheet — `start_date` / `end_date`

| Layer | Says / does |
|-------|-------------|
| **Spec says** | **UI:** `dd/MM/yyyy` (BR-UX-DATE-01/02 · L-DATE). **Wire:** TechSpec §12.1 sample `"start_date":"2026-07-01"` (`YYYY-MM-DD`). SRS BR-ATT-SHEET-04: thiếu ngày / start>end → từ chối. FR-HRM-AT-14 / AC-ATT-SHEET-01..06: POST **201** header-only; list hiện kỳ. |
| **Code does (FE)** | `apps/web/hrm/src/pages/Attendance.tsx` (~443–477, ~3085–3099): free-text `<Input>` + **decorative** `Calendar` icon (`pointer-events-none`) — **không** Popover/CalendarComponent. Default: `toLocaleDateString('en-GB')` → padded `01/07/2026`. Submit: naive `split('/')` → `` `${y}-${m}-${d}` `` **không zero-pad**. `timePreset` Select **không** recalc dates. Leave tab **có** real Popover+Calendar (`z-50`) — sheet modal không. |
| **Code does (BE)** | `CreateAttendanceSheetDto`: `@IsDateString()` on `start_date`/`end_date`. Spec `be-hrm-c-conv-as-01.spec.ts` **rejects** `'01/07/2026'`. Service INSERT `$4::date,$5::date` — **chưa** assert start≤end (gap vs BR-ATT-SHEET-04). |
| **DB stores** | `public.attendance_sheets.start_date` / `end_date` **DATE NOT NULL** (`AttendanceCatalogService.ensureAttendanceSheetSchema`). |

**Mismatch class:** FE entry UX ≠ L-DATE picker; FE→ISO pad broken for unpadded `d/M/yyyy` → Nest 400 «invalid» = sponsor submit fail.

### 1.2 Company «Ngày thành lập» (`founded_date`)

| Layer | Says / does |
|-------|-------------|
| **Spec says** | UX AC: calendar date → display `dd/MM/yyyy`; null → `—`. Org SoT XBOS legal entity: DTO `establishedAt` → column `established_at DATE` (`org-foundation.service` upsert). HRM company screen is consumer of group member units (portal embed). |
| **Code does (FE)** | `CompanyManagement.tsx`: form `founded_date: z.date().optional()`; Popover+Calendar; display `format(...,'dd/MM/yyyy')`. **Load:** portal → `fetchGroupMemberUnitsForHrm` → `mapGroupMemberUnitsToHrmCompanies` **hardcodes** `founded_date: null`, `tax_code/email/phone/address: null`. **Save:** `onSubmit` builds `companyData` rồi **toast only** — **không** PUT legal-entity / HRM company API. |
| **Code does (API)** | `GET /api/xbos/tenant-scope/group-member-units` → `listGroupMemberUnits()` SELECT **không** gồm `tax_code`, `established_at`, email/phone — chỉ `id,code,name,entity_type,payload`. Upsert path **có** `established_at` nhưng HRM company UI không gọi. |
| **DB stores** | `public.xbos_legal_entity.established_at DATE` (+ `tax_code`, `address`, …). **Không** có cột `founded_date` trên path này. Supabase types `companies.founded_date` = legacy surface, **không** dùng trên portal embed path. |

**Mismatch class:** projection stub + missing SELECT fields + non-persisting save — empty «Ngày thành lập» / «—» là **data bind**, không chỉ picker z-index.

## 2. Root-cause options (picker + invalid submit)

| Option | Hypothesis | Evidence | Fits ATT? | Fits CO? |
|--------|------------|----------|-----------|----------|
| **A — Locale parse** | `split('/')` + unpadded `1/7/2026` → `2026-7-1` fails `@IsDateString`; `vi-VN` locale produces unpadded; sponsor `01/01` vs `1/1` | Node: `en-GB`→`01/07/2026`, `vi-VN`→`1/7/2026`; BE rejects `dd/MM/yyyy` | **Primary** for invalid submit | Secondary (ISO map if save wired) |
| **B — Native / fake input** | Sheet dates = free text; calendar icon `pointer-events-none` → «picker không mở» | Attendance.tsx sheet modal | **Primary** for picker | N/A (CO has real Calendar) |
| **C — Zod / class-validator ISO-only** | Wire must be ISO; FE gửi locale → 400 | DTO + CONV-AS-01 spec | **By design** (keep) | `founded_date` zod `z.date()` OK if Calendar works |
| **(+ CO) Popover z-index / portal** | Calendar clipped under Dialog in embed | `popover.tsx` already `z-50` / parent `z-[100010]` | Low for ATT (no Popover) | Possible secondary after bind fixed |

**SA synthesis:** INC-DATE-ATT-SHEET = **B (no picker) + A (unsafe parse)**; C is correct gate, not a bug to remove. INC-DATE-CO-FOUND = **missing XBOS field projection + fake save**; z-index only after data path exists.
