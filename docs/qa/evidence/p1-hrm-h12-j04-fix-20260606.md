## Root cause

Insurance list rows could render employee name as plain text when `employee_id` was absent on the API row (catalog/participant seed with `employee_code` + `employee_name` only). `Insurance.tsx` already gated `Link` on `employee_id` truthy — QA CDP `hasLink: false` for «Lê Văn An» / `LOG-0003`.

## Fix

| Area | Change |
|------|--------|
| **useInsuranceList** | Parallel `listAllInsuranceRecords` + `listEmployees`; `findEmployeeForInsuranceRow` resolves profile id by `employee_id`, then `employee_code`, then `employee_name` |
| **mapApiInsuranceToListItem** | `normalizeInsuranceEmployeeId`; fallback `employee_id` from matched workforce row |
| **Insurance.tsx** | Employee name `Link` matches `Contracts.tsx` (`hrmPathWithEmbedSearch`, `stopPropagation`); view dialog name also linked |
| **U34** | Unchanged — refetch on add/edit dialog close retained |
