## Scope delivered (S1)

### org-foundation (`UC-XBOS-ORG-01`..`03`, `UC-XBOS-10`)
- Routes unchanged; **claim-first** `resolveScopeContext` on all org mutations/reads.
- **ADR alignment:** group legal-entity plane uses `companyId=holding` aligned with JWT; `main` vs `holding` drift → **409** `SCOPE_CONTEXT_MISMATCH` (not empty 200).
- Member subsidiary ops use `companyId=main` per ADR §3.2.

### position-rbac (`UC-XBOS-11`, `UC-XBOS-12`)
- **Templates / matrix / permissions:** `resolveTenantOnlyContext` (tenant gate only).
- **Assignments / grants / conflicts:** full `resolveScopeContext` (tenant + company).

### tenant-scope (membership / Command Center)
- `accessible`, `group-org-overview`, `group-member-units` — JWT `sub` / email; **no** `companyId` scope gate on controller.
- Group-only paths return **403** `XBOS-TENANT-403` when user lacks master membership (ADR rung 1 vs rung 2).

### OpenAPI
- ADR-HRM-RBAC reference in spec `info.description`.
- **409** / **401** / **403** documented on org + tenant group paths.
- Added `positionRbacGetMatrix` / `positionRbacSaveMatrix` paths.

### Deferred (ADR Target, out of S1 BE-03 slice)
- `POST /auth/select-membership` portal JWT re-issue — tracked in ADR §5.3 Target; login default + `accessible` only in S1.
