## Summary

Closed **R-H10-01**: per-company `contract_ratio` for **`trsport`** and **`finance`** was **0.077** / **0.280** vs target **≥ 0.95**. Root cause: global hash cohort in `seed-hrm-satellite-from-workforce.mjs` plus legacy rows where `employee_contracts.company_id` did not match `employees.company_id` (AC-FID-03 uses same-slug join).

**Fix:** per-company contract cohort (95% deterministic by `employee_code`), AC-FID-03-aligned backfill in `seed-hrm-contracts-density.mjs` (realign + insert), idempotent re-run on pilot DB.

## Root cause

| Factor | Detail |
|--------|--------|
| **Symptom** | QA SQL: `trsport` 16/207 (0.077), `finance` 58/207 (0.280) with `ec.company_id = e.company_id` |
| **Cohort** | `inCohort('contract', employee_code)` global hash → uneven distribution by company |
| **Partition drift** | Some contracts stored under mismatched `company_id`; counted in global ratio but not AC-FID-03 per-slug ratio |
