## Problem

| Symptom | Probe | Before |
|---------|-------|--------|
| Command Center catalog inbox empty / blocked | `GET /api/xbos/catalog-governance/inbox` with portal Bearer (`companyId=main`) | **409** `SCOPE_CONTEXT_MISMATCH` |

**Root cause:** `CatalogGovernanceController.resolveGroupScope` used strict `resolveScopeContext` on **read** routes; group CEO JWT `main` did not match default query partition `holding`.

**ADR:** `docs/architecture/ADR-GROUP-CEO-MAIN-HOLDING-SCOPE.md` — same pattern as S2-D-01/D-03 (`resolveXbosGroupLegalReadScopeContext`).

## Fix

| File | Change |
|------|--------|
| `apps/api/xbos-api/src/catalog-governance/catalog-governance.controller.ts` | `resolveGroupReadScope` → `resolveXbosGroupLegalReadScopeContext` on `GET inbox`, `GET instances/:id`; writes (`approve`/`reject`/`seed`) keep `resolveGroupWriteScope` → strict `resolveScopeContext` |
| `apps/api/xbos-api/src/catalog-governance/catalog-governance.controller.spec.ts` | C6 jest: group CEO JWT `main` → inbox/detail **200**; holding JWT + query `main` still **409** |
