## Contract (FE CD-FB-04 coordination)

### Request (ADDITIVE)

```
GET /api/hrm/employees?company_id=main&page_size=100
GET /api/hrm/employees?company_id=main&page_size=100&cursor=<next_cursor>
```

- `cursor` absent → OFFSET `page` (must_keep)
- `cursor` set → keyset `(created_at, id) < cursor`; `page` ignored
- `view=directory` + `cursor` → **400** `HRM-EMP-CURSOR-002`
- Invalid cursor → **400** `HRM-EMP-CURSOR-001`

### Response (ADDITIVE field)

```json
{
  "total": 1107,
  "page": 1,
  "page_size": 100,
  "next_cursor": "<opaque>|null",
  "data": [ /* employees */ ]
}
```

- `total` = **full scoped count** (not remaining-after-cursor)
- First page (no cursor) also returns `next_cursor` when more rows exist — FE can switch to cursor for page 2+

### FE walk (copy-ready)

```ts
let cursor: string | undefined;
const all = [];
for (;;) {
  const res = await listEmployees({ company_id, page_size: 100, cursor });
  all.push(...res.data);
  if (!res.next_cursor) break;
  cursor = res.next_cursor;
}
```

Dashboard stays on `getEmployeesSummary()` — **do not** reintroduce listAllEmployees for tiles.
