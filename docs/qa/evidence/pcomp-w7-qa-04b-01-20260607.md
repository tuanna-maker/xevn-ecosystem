## Live API — J-MOB-09 (whos_out) — FAIL

**Request (mobile primary path per TechSpec):**

```http
GET /api/hrm/home/summary?company_id=holding&employee_id={uat_emp}&include=whos_out
```

**Result:** HTTP **500** · `HRM-SYS-001` · `invalid input syntax for type uuid: "holding"`

Same failure for combined:

```http
GET /api/hrm/home/summary?company_id=holding&employee_id={uat_emp}&include=celebrations,whos_out
```

**Root cause (code):** `buildWhosOut` casts `query.company_id` to `::uuid` when scope is not master rollup (`home.service.ts` ~L324–326). `celebrations` uses `pushWorkforceEmployeeScopeFilter` and accepts slug `holding`; `whos_out` does not — scope parity gap.

**UUID attempt:** `company_id=6efaa5d6-a4a8-4bfd-805a-3c4f003e4013` → HTTP 404 `HRM-HOME-404` (viewer load).
