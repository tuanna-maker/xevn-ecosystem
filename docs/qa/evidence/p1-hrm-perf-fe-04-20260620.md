## Problem

HRM Dashboard (`Index` → `Dashboard.tsx`) mounted `useEmployees()` → `listAllEmployees` **~12** paginated `GET /employees` calls (~1107 NV).  
`ExpiringContractsAlert` + sidebar contract reminder each fetched `listAllEmployeeContracts` separately (duplicate).

## Solution

| Area | Before | After |
|------|--------|-------|
| Dashboard headcount / payroll / charts | `useEmployees` → ~12 list pages | **1×** `GET /api/hrm/employees/summary` via `useEmployeesSummary` |
| Embed stats tile (`PortalOperationsSummary`) | `useEmployees(true)` list storm | `useEmployeesSummary({ include_archived: true })` |
| Expiring contracts | 2 queries (`expiring-contracts-count` + `expiring-contracts-dashboard`) | **1×** shared `useExpiringContractsDashboard` (RQ dedupe) |
| Global cache | `new QueryClient()` default staleTime 0 | **60_000 ms** default `staleTime` in `App.tsx` |
