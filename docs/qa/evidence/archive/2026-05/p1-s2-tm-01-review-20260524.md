## Security review — CC catalog publish flows

### Controls in place (PASS)

| Control | Evidence |
|---------|----------|
| Catalog publish/bootstrap requires internal auth | `config-sync.controller` `assertInternalAccess`; jest rejects unauthenticated publish |
| Catalog governance routes require auth | `catalog-governance.controller` `assertAccess` on inbox/approve/reject/seed |
| Publish body scope aligned to JWT | `resolveScopeContext` on publish body; jest rejects companyId drift |
| Config read scope enforced before DB | `getCatalogForSystem` scope check; mismatch → 409 before service |
| Audit list requires internal auth | `platform-audit.controller` rejects unauthenticated |
| FE session uses JWT when logged in | `buildApiAuthHeaders` — Bearer portal token, not dev key |
| KPI rollup alias role-gated | ADR §4 + `resolveKpiRollupScopeContext`; QA rollup 200 PASS |

### Gap — CC catalog governance with portal JWT (NEW)

**Problem:** `CatalogGovernanceController.resolveGroupScope` defaults query `companyId` to **`holding`** when omitted. Portal group CEO JWT carries **`main`**. `resolveScopeContext` returns **409** when claim `main` and requested `holding` both present.

**Impact:** Seed/script path works (`x-internal-api-key` only — no JWT claim). **Logged-in** `ceo@xe.vn` calling inbox/approve via `catalogGovernanceApi.ts` (no `companyId` query) is **blocked** — `BTN-A2-CATALOG-GOV-APPROVE/REJECT` cannot complete under real session.

**Risk level:** **Major** (functional + governance path broken for primary persona; not a security bypass).

**Options:**

| Option | Trade-off | TM recommendation |
|--------|-----------|-------------------|
| A — `resolveCatalogGovernanceScope` helper (group CEO `main` + request `holding` alias, mirror KPI) | Consistent with ADR §4 catalog partition; requires jest | **Preferred** — dev-be |
| B — FE passes `companyId=main` only | May read wrong partition if data under `holding` | Rejected for catalog SoT |
| C — Default `resolveGroupScope` to `main` when JWT `main` | Hides seed partition mismatch | Rejected — data integrity |

**Verification:** Authenticated probe `GET/POST catalog-governance/inbox` + approve with portal JWT → **200**, not 409; extend L2 matrix row.
