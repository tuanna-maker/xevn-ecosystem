## Plan — QC prod gate execution steps (TLS + PROD lift)

### A) TLS perimeter for xevn (safe on shared VPS)

1. **Pick domain(s)** for production endpoints (examples):
   - `portal.<domain>` → proxy to `127.0.0.1:8088`
   - `hrm-api.<domain>` → proxy to `127.0.0.1:3001`
   - `xbos-api.<domain>` → proxy to `127.0.0.1:28002`
2. **Provision cert** (Let’s Encrypt or corporate CA).
3. Create `/etc/nginx/sites-available/xevn-ecosystem` with:
   - `listen 80; return 301 https://$host$request_uri;`
   - `listen 443 ssl http2;` + `add_header Strict-Transport-Security ... always;`
   - `proxy_set_header X-Request-Id $request_id;` and standard proxy headers
4. `nginx -t && systemctl reload nginx`
5. Verify (must PASS for QC prod gate):
   - `curl -I http://<xevn-host>/` returns **301** → https
   - `curl -Ik https://<xevn-host>/` includes `Strict-Transport-Security`

### B) Production smoke (over TLS, not raw ports)

- Portal:
  - `curl -Ik https://portal.<domain>/command-center` → 200/302 (no 5xx)
- APIs:
  - `curl -Ik https://hrm-api.<domain>/api/hrm/metrics?format=prometheus`
  - `curl -Ik https://xbos-api.<domain>/api/xbos/metrics?format=prometheus`
