## Root cause

Portal auth uses `public.xbos_portal_user` + `xbos_user_tenant_membership`. Tourism mobile seed (`seed:tourism:mobile-pilot`) only provisions HRM `employees` + mobile password hash — **not** XBOS portal rows. `du-lich.ceo@xe.vn` worked via `auth.service` dev bootstrap + `seed:tenant-ceos`; **HRBP was never in that list**.
