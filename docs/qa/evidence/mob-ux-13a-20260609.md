## Summary

Refactored `CheckInScreen` from dev form (editable UUID + «Bật GPS/geofence») to Apple HIG grouped self-service: hero card with `full_name` + `employee_code` from session/API, auto `expo-location` capture on focus/submit, Vietnamese «Vị trí thiết bị» copy, sticky primary CTA «Chấm công vào» + secondary «Lịch sử chấm công». Removed employee chip picker and manual lat/lng toggle.

## Changes

| Area | Before | After |
|------|--------|-------|
| Identity | Editable `FormField` «Mã nhân viên» showing UUID | `CheckInHeroCard` — avatar/initials, `full_name`, read-only `employee_code` via `fetchEmployeeById` + membership fallback |
| Location | Toggle «Bật GPS / geofence» + manual lat/lng | `expo-location` foreground permission (Việt rationale in `app.json`); labels «Vị trí thiết bị» / «Đang lấy vị trí…» — **no** GPS/geofence strings |

| CTA | Ghost history inline | `StickyFooter`: primary «Chấm công vào» + ghost «Lịch sử chấm công» |
| Submit body | Coords only when manual toggle on | `buildCheckInSubmitBody()` — coords when permission granted + finite values |
| Spacing | Mixed | Grouped `AppScreenLayout` + `ProfileSectionCard` with `layout.itemGap` / `sectionGap` per DS §3 |
