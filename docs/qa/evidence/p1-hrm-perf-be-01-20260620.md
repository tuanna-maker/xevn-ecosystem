## Problem

Embed HRM on `:8088` (~1107 NV) — `listAllEmployees` loops **~12** sequential `GET /employees?page_size=100` for dashboard/count widgets.

## Solution

New endpoint **`GET /api/hrm/employees/summary`** — single round-trip aggregates using **same** `resolveHrmListScope` / `buildEmployeeListFilters` as list.

| Field | Purpose |
|-------|---------|
| `total`, `active_count`, `inactive_count`, `archived_count` | Dashboard headcount |
| `payroll.total`, `payroll.employees_with_salary` | Salary widgets (from `custom_fields.salary` / `base_salary`) |
| `by_department[]` | Department breakdown |
| `salary_ranges[]` | Dashboard range chart buckets |
| `new_hires.last_30_days`, `new_hires.recent[]` | Sidebar / comparison widgets |

**Response code:** `HRM-EMP-SUMMARY-200`
