## Fix (BE)

1. **Metadata DTO** — `company_id` → `@IsString() @MaxLength(64)`; optional `tenant_id` for portal embed.
2. **Metadata list** — `resolveHrmListScope` + `pushCompanyIdTextColumnFilter` on `employee_metadata_change_requests` (slug rollup `main` → member slugs).
3. **Operations summary** — `getSummary(companyId, authorization)` with scoped counts: `pushCompanyIdFilter` (payroll/job reqs), `pushWorkforceEmployeeScopeFilter` (attendance), `pushCompanyIdTextColumnFilter` (tasks/service requests).
4. **Shared** — `pushCompanyIdTextColumnFilter` in `hrm-list-scope.ts` for UUID columns compared as text.
