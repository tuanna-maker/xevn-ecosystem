## Root cause

`PerformanceService.ensureSchema()` (E3) ran `DROP CONSTRAINT` + `ADD CONSTRAINT chk_performance_evaluation_status` on **every** list/create request. When legacy `performance_evaluations` rows had `status` NULL, empty, or outside `{draft,submitted,approved,completed}`, PostgreSQL rejected `ADD CONSTRAINT` → unhandled exception → HTTP **500**.

Pattern matches prior fix in `contracts-insurance.service.ts` (repair bad rows before idempotent constraint add).

## Fix (FIX — preserve E3 SM/PATCH/DELETE)

**File:** `apps/api/hrm-api/src/performance/performance.service.ts`

1. Add `status` column as nullable IF NOT EXISTS.
2. `UPDATE` invalid/null status → `'draft'`.
3. Set DEFAULT + NOT NULL on `status`.
4. Replace DROP/ADD with idempotent `DO $$ … IF NOT EXISTS (pg_constraint) … ADD CONSTRAINT`.
