### Endpoint

```
GET /api/hrm/home/summary?company_id={slug|uuid}&employee_id={uuid}&include=celebrations,whos_out
```

**Headers:** `Authorization`, `x-tenant-id`, `x-company-id` (standard HRM).

### Celebrations (BR-BDAY-*)

| Rule | Implementation |
|------|----------------|
| BR-BDAY-02 | Response items: `month_day` (`MM-DD`), `display_date` (`DD/MM`); **no** `birth_year`, **no** `date_of_birth` in JSON |
| BR-BDAY-03 | Invalid/null DOB omitted in SQL regex + post-filter |
| BR-BDAY-04 | `todayMonthDayInHoChiMinh()` via `Intl` + `Asia/Ho_Chi_Minh` |
| BR-BDAY-06 | Same scope stack as `loadViewer`: `pushWorkforceEmployeeScopeFilter` on `e.id` |
| C2 | `status = 'active'` AND `archived_at IS NULL` |

### Whos_out (BR-WHO-*)

| Rule | Implementation |
|------|----------------|
| BR-WHO-01 | `lr.status = 'approved'` only |
| BR-WHO-02 | `covering_date = todayIsoInHoChiMinh()` → `$n::date BETWEEN lr.start_date AND lr.end_date` |
| Scope | `pushWorkforceEmployeeScopeFilter` on `lr.employee_id` for master tenant rollup; else `lr.company_id` UUID match |
