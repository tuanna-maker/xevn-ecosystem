## Summary

|------|--------|

| `mainTabIa.test.ts` | Import `MAIN_TAB_COUNT` from `mainTabIa` only — no `checkInFab` / `react-native` chain |

No runtime / navigation behavior change; single source of truth for 4-tab lock.
