## 1. Data contract matrix — FE → DTO → column → type → null rules

### 1.1 Company «Ngày thành lập» (`founded_date` / XBOS `established_at`)

| Layer | Field | Type / wire | Null rule | Spec / code ref |
|-------|-------|-------------|-----------|-----------------|
| **FE label** | Ngày thành lập | Display `dd/MM/yyyy` (UX AC); empty → `—` / `-` | Optional on view | `CompanyManagement` view; `UX_VI_DATE_NUMBER_FORMAT_AC.md` |
| **FE form** | `founded_date` | `z.date().optional()` → submit `format(..., 'yyyy-MM-dd')` or `null` | Optional; omit → `null` | `CompanyManagement.tsx` schema + `onSubmit` |
| **FE list bind (embed)** | `HrmCompanyRow.founded_date` | always **`null`** from mapper | **Hard-null** — không đọc SoT | `tenantScopeApi.mapGroupMemberUnitsToHrmCompanies` |
| **DTO wire (XBOS SoT)** | `establishedAt` / `established_at` | **date** string `YYYY-MM-DD` | Optional; empty trim → omit/`null` | `UpsertLegalEntity` · `org-foundation.service` `$8::date` |
| **DB SoT (legal)** | `public.xbos_legal_entity.established_at` | **`DATE`** (calendar) — **not** timestamptz | **NULL allowed** | seed DDL `ADD COLUMN … DATE` |
| **DB legacy (HRM)** | `public.companies.founded_date` | string date in types (`string \| null`) — treat as **DATE** calendar | **NULL allowed** | `supabase/types.ts` `companies.Row` |
| **Audit stamps** | `created_at` / `updated_at` | **TIMESTAMPTZ** | NOT NULL DEFAULT NOW() | legal entity + companies + sheets |

**Deterministic rules**

| ID | Condition | Rule | Expected |
|----|-----------|------|----------|
| **VAL-CO-FOUND-01** | User picks founded date | Persist as calendar **DATE** `YYYY-MM-DD` (no TZ shift) | DB date = day user chose; FE F5 = `dd/MM/yyyy` |
| **VAL-CO-FOUND-02** | User clears date | Store `NULL` | FE shows `—` |
| **VAL-CO-FOUND-03** | Invalid / non-ISO on API | Reject 400 | No silent coerce from `dd/MM/yyyy` on wire |
| **VAL-CO-FOUND-04** | Embed group-member-units only | Mapper nulls founded | UI empty **even if** `established_at` filled in legal entity → **bind bug** |

### 1.2 Attendance sheet period (`start_date` / `end_date`)

| Layer | Field | Type / wire | Null rule | Spec / code ref |
|-------|-------|-------------|-----------|-----------------|
| **FE form** | `newSheetForm.startDate` / `endDate` | UI string via `toLocaleDateString('en-GB')` (often `dd/MM/yyyy`, **may unpad** `1/7/2026`) | Required for Lưu | `Attendance.tsx` |
| **FE → API** | split `/` → `` `${y}-${m}-${d}` `` | Intended ISO; **no zero-pad** if locale unpads | Required | `handleAddSheet` |
| **DTO** | `CreateAttendanceSheetDto.start_date` / `end_date` | `@IsDateString()` → **ISO `YYYY-MM-DD`** | **Required** (NOT NULL) | `create-attendance-sheet.dto.ts` |
| **DB** | `attendance_sheets.start_date` / `end_date` | **`DATE NOT NULL`** | **Never null** on insert | `ensureAttendanceSheetSchema` |
| **DB meta** | `created_at` / `updated_at` | **TIMESTAMPTZ NOT NULL** | Default NOW() | same DDL |
| **Period naming** | No `period_start`/`period_end` on sheets | Use **`start_date`/`end_date` only** | — | TechSpec §12.1 · FR-HRM-AT-14 |

## 2. Holding «Tập đoàn XeVN» empty MST / email / phone — SoT + hypothesis

### 2.1 Dual-plane SoT (authoritative)

| Field on HRM Company UI | Authoritative SoT | Table / column | Fill API (Command Center) | Not SoT |
|-------------------------|-------------------|----------------|---------------------------|---------|
| **Tên** | XBOS tenant registry **or** legal entity name | `xbos_tenant_registry.name` (holding list) · `xbos_legal_entity.name` | Org foundation legal-entities | FE hardcode |
| **MST** | XBOS legal entity | `xbos_legal_entity.tax_code` **and/or** `payload.companyForm.taxCode` | `GET/PUT …/org-foundation/legal-entities` | `group-member-units.holding` (no tax) |
| **Ngày thành lập** | XBOS legal entity | `established_at` **DATE** · `payload.companyForm.firstIssueDate` | same PUT | tenant-scope holding blob |
| **Email** | Legal entity **payload** (no dedicated column) | `payload.companyForm.companyEmail` | same | HRM `companies.email` unless product locks HRM mirror |
| **Phone / hotline** | Legal entity **payload** | `payload.companyForm.hotline` / `legalRepPhone` | same | tenant-scope |
| **Address** | Legal entity | `address` · `payload.companyForm.headOfficeAddress` | same | — |

**Plane B (operating):** HRM workforce slug `holding` on employees/sheets — **not** the profile SoT for MST/contact.

**Legacy plane:** `public.companies` (`tax_code`, `email`, `phone`, `founded_date`) exists in HRM types but **embed path does not read/write it**.

### 2.2 What embed actually loads today

```
CompanyManagement (portal embed)
  → GET /api/xbos/tenant-scope/group-member-units
  → listGroupMemberUnits(): holding = ONLY (tenant_id, name, short_name) FROM xbos_tenant_registry
  → mapGroupMemberUnitsToHrmCompanies(): tax_code=email=phone=founded_date=null (hard)
  → synthetic id: `xbos-group-holding-root`
```

Members join `xbos_legal_entity` but mapper **still nulls** tax/email/phone/founded (only uses `payload.shortName` → description).

**Save path:** `onSubmit` / delete = **toast-only**, then `fetchCompanies()` reload — **no PUT** to org-foundation or HRM companies → edits cannot persist.

### 2.3 Hypotheses (ordered)

| ID | Class | Verdict | Evidence |
|----|-------|---------|----------|
| **H1 BIND** | FE binds wrong API + hard-null mapper | **PRIMARY** | `tenantScopeApi.ts` L63–81; `CompanyManagement` embed-only fetch |
| **H2 API SHAPE** | `group-member-units` holding omits legal profile columns | **CONTRIBUTING** | `listGroupMemberUnits` SELECT tenant_registry only for holding |
| **H3 ORPHAN ID** | Synthetic `xbos-group-holding-root` ≠ legal entity UUID / slug `holding` | **CONTRIBUTING** | Cannot deep-link PUT legal-entity without resolver |
| **H4 DATA EMPTY** | SoT row `tax_code`/`established_at`/`companyForm` still NULL in DB | **SECONDARY** — probe after bind fix; **not** seed to invent U65 | May coexist with H1 |
| **H5 HRM companies orphan** | Row in `companies` filled but unused by embed | **POSSIBLE** dual-write debt | FE never selects `companies` in portal mode |

**Recommendation (governance → execution):** Bind company detail to **org-foundation legal entity** for holding (`company_id=holding` / entity_type holding) — map `tax_code`→MST, `established_at`→founded, `payload.companyForm.companyEmail`→email, `hotline`→phone. Keep `group-member-units` for **member list navigation only**. Persist via existing UF-XBOS legal PUT — **not** fake toast. Do **not** seed MST to pass QA.
