## Scope

Post-fix review of HRM list DTOs used by Command Center embed probes `company_id=main` (P-CC-06..08) and `page_size` on payslips.

## Findings

| Route / probe | DTO | `company_id` | `page_size` | TM |
|---------------|-----|--------------|-------------|-----|
| P-CC-06 recruitment | `list-job-requisitions.query.dto.ts` | `@IsString()` `@MaxLength(64)` | `@Min(1)` `@Max(100)` | **APPROVE** |
| P-CC-07 attendance | `list-attendance-records.query.dto.ts` | same | same (`@Transform` for ints) | **APPROVE** |
| P-CC-08 payroll | `list-payroll-payslips.query.dto.ts` | same | same (`@Type(() => Number)`) | **APPROVE** |
| P-CC-08 periods (if used) | `list-payroll-periods.query.dto.ts` | `@IsString()` | n/a | **APPROVE** |

**Root cause (fixed):** `@IsUUID()` on `company_id` rejected portal slug `main` → **400** `HRM-VAL-001` under `ValidationPipe` (`whitelist` + `forbidNonWhitelisted`). Slug `main` is valid for `resolveScopeContext` → `assertScopeId` (`^[a-zA-Z0-9][a-zA-Z0-9_-]{1,62}$`) when JWT `companyId` matches.

**DB:** `attendance.service` / `payroll.service` migrate `company_id` to **TEXT** — consistent with slug + UUID storage.

**Payslips `page_size`:** Field required because L2 smoke calls `?page_size=100`; without it, whitelist rejects the query. DTO bounds **1..100** are correct.

**Gap (non-blocking S0):** `PayrollService.listPayslips()` does not apply `page` / `page_size` (returns full filtered set). Acceptable for pilot empty/small tenants; track **P1-S1-BE-PAY-PAGE** before large payslip volumes.

## Drift (defer S1)

- Other list DTOs still use `@IsUUID()` on `company_id` (e.g. `list-leave-requests`, `list-attendance-update-requests`) — not on P-CC-06..08 primary load; harmonize to `@IsString()` when those routes enter matrix.
- Pagination transform style differs (`@Transform` vs `@Type`) — cosmetic; no S0 gate impact.
