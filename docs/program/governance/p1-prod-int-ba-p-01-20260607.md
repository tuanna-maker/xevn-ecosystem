## 5. Cross-module journey AC — J-HRM-INT-*

List→detail and cross-tab journeys **must preserve** the same **`company_id` slug** (or rollup context) and **`employee_id`** UUID.

| Journey ID | Click path | Modules | Pass criteria (measurable) | Persona |
|------------|------------|---------|---------------------------|---------|
| **J-HRM-INT-01** | P-CC-06 requisition row → detail → linked candidate → (hire) | Recruitment | `requisition.company_id` = `candidate.company_id`; status `filled` ⇒ `employee_id` NOT NULL | Group CEO rollup + member CEO single slug |
| **J-HRM-INT-02** | P-CC-03 employee row → P-CC-04 contracts tab/filter same NV | Employees → Contracts | `GET /employees/:id` **200**; `GET /contracts?employee_id=` returns ≥1 row; same slug as list row | Extends **J-HRM-01** |

## 6. Business rules — BR-INT-01..05

| Mã | Điều kiện | Hành động | Kết quả | HTTP / mã lỗi |
|----|-----------|-----------|---------|----------------|
| **BR-INT-01** | JWT master tenant + `companyId=main` + role `group_ceo` or `group_*` + list query `company_id=main` or `all` | BE `resolveHrmListScope` → `companyIds` = all `GROUP_MEMBER_SLUGS` | Rollup list/get parity | **200**; not literal `company_id='main'` only |
| **BR-INT-02** | JWT member tenant + `companyId=main` + role `subsidiary_ceo` | SQL filter `custom_fields.tenant_id = JWT.tenantId` AND `company_id='main'` | No cross-tenant rows | **200** scoped; group APIs **403** |
| **BR-INT-03** | Group CEO selects company slug S in embed switcher | FE sends `company_id=S` on module APIs; **does not** mutate JWT `companyId` | Filtered dataset for S | **409** if S ∉ membership slugs |
| **BR-INT-04** | User navigates list→detail across modules for entity E | get-by-id / linked APIs use **same** scope resolver as list for persona | Detail **200** with matching `employee_id` + slug | **404** if out of scope; **409** if query JWT mismatch |
| **BR-INT-05** | Cardinality reconciliation (XBOS ↔ HRM) | Count legal entities with HRM ops role in XBOS `group-member-units` = count distinct `employees.company_id` slugs in master partition (excluding `main` literal-only empty) | Seed/script **PASS** or documented gap + owner | N/A (batch gate) |
