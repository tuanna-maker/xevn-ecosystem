### 4.3 Legacy script migration notes (for Dev/QA)

1. **Port:** Replace `3001` → `$env:HRM_BE_PORT ?? 28001`.
2. **Auth:** Phase 0 obtains **portal JWT**; service JWT chỉ cho internal/bootstrap nếu cần.
3. **Scope headers:** Mọi request: `Authorization: Bearer {portalJwt}`, `x-tenant-id: xevn`, `x-company-id: main` (query `company_id=main` đồng bộ).
4. **Synthetic POST:** Chỉ chạy trên **UUID member company từ seed** (không random GUID) hoặc skip nếu L1 P5 đã cover persistence.
5. **Step 6 / UAT-G3-12:** Thêm `tenantId` trong body hoặc header; nếu FAIL → verdict **GWC** not **FAIL G3** (S3-D-01).
6. **Exit artifact:** JSON summary `{ phase, uc_cluster, pass, http_code, evidence_path }` → attach to `p1-p100-w11-qa-02-*.md`.
