## 1. Problem & scope

User incident **1OFFICE mock** exposed a deeper integrity class: HRM charts and rollups use **`company_id` operating slugs** on the master tenant, while Command Center org uses **member-tenant legal entities** from XBOS org-foundation. Without an explicit cross-plane contract, FE joins wrong dimension → labels like **`Khác`** (G-INT-02) or static fiction; QA cannot prove cardinality parity (G-INT-03).

**In scope (this artifact):** data contract table, reconciliation probes, BR-DQ-01 extension, display-name SoT per `GROUP_MEMBER_SLUG`, department join keys.

**Out of scope:** FE implementation (`P1-PROD-INT-FE-01`), seed script edits (`P1-PROD-INT-BE-01` execution).

## 2. Dual identifier planes (do not conflate)

```text
Plane A — XBOS org / tenant registry (legal persons)
  xbos_tenant_registry (member tenants: xe-tmdv, visun, xe-du-lich, xe-vietnam)
  xbos_legal_entity (name, code, id UUID)
  API: GET /api/xbos/tenant-scope/group-member-units
       GET /api/xbos/org-foundation/legal-entities  (group CEO → flat member list)

Plane B — HRM master workforce partition (operating slugs)
  GROUP_MEMBER_SLUGS = holding | trsport | logistics | finance | services
  employees.company_id, departments.company_id, satellite tables
  API: GET /api/hrm/*?company_id=main  (rollup via resolveHrmListScope)
```

| Plane | Count (pilot seed target) | Primary key on HRM rows | Display label SoT |
|-------|-------------------------|-------------------------|-------------------|
| **A** — member legal entity | 4 subsidiaries + 1 holding legal row | Member CEOs: `tenant_id` + `company_id=main` | `xbos_legal_entity.name` via `group-member-units` |
| **B** — operating slug | **5** slugs on `tenant_id=xevn` | `employees.company_id` ∈ `GROUP_MEMBER_SLUGS` | See §5 — **holding** from XBOS; **trsport…services** require `company_slug_map` extension (G-INT-03) |

**Cardinality rule (G-INT-03):** For group CEO rollup charts that aggregate by **`employees.company_id`**, every distinct slug in Plane B must have (a) ≥1 active employee row, (b) a resolvable **display name** in SoT, (c) optional **bridge** to Plane A when business maps slug ↔ member tenant. **Current pilot:** Plane A count (4 members) ≠ Plane B count (5 slugs) — documented **seed gap** until `P1-PROD-INT-BE-01` publishes bridge rows.

## 7. Reconciliation probes — automate (QA + dev-be)

### 7.1 SQL probes (HRM DB — `xevn_hrm`)

```sql
-- REC-INT-SQL-01: distinct operating slugs (expect 5)
SELECT company_id, COUNT(*) AS active_count
FROM employees
WHERE status = 'active' AND archived_at IS NULL
  AND company_id IN ('holding','trsport','logistics','finance','services')
  AND (custom_fields->>'tenant_id' = 'xevn' OR custom_fields->>'tenant_id' IS NULL)
GROUP BY company_id
ORDER BY company_id;

-- REC-INT-SQL-02: orphan slug detection (expect 0 rows)
SELECT DISTINCT e.company_id
FROM employees e
WHERE e.status = 'active' AND e.archived_at IS NULL
  AND e.company_id NOT IN ('holding','trsport','logistics','finance','services','main')
  AND (e.custom_fields->>'tenant_id' = 'xevn' OR e.custom_fields->>'tenant_id' IS NULL);

-- REC-INT-SQL-03: company_slug_map cardinality (expect 5)
SELECT company_slug, company_uuid::text
FROM company_slug_map
WHERE tenant_id = 'xevn'
ORDER BY company_slug;

-- REC-INT-SQL-04: departments per slug (expect ≥1 each)
SELECT company_id, COUNT(*) AS dept_count
FROM departments
WHERE status = 'active'
  AND company_id IN ('holding','trsport','logistics','finance','services')
GROUP BY company_id;

-- REC-INT-SQL-05: satellite FK integrity sample (contracts)
SELECT e.company_id, COUNT(DISTINCT e.id) AS emp, COUNT(c.id) AS contracts
FROM employees e
LEFT JOIN employee_contracts c ON c.employee_id = e.id AND c.company_id = e.company_id
WHERE e.status = 'active' AND e.archived_at IS NULL
  AND e.company_id IN ('holding','trsport','logistics','finance','services')
GROUP BY e.company_id;
```

**PASS:** SQL-01 returns exactly 5 slugs; SQL-02 empty; SQL-03 five UUIDs matching `hrm-list-scope.ts` map; SQL-04 five rows with `dept_count ≥ 1`; SQL-05 contract ratio ≥ 0.85 per slug (AC-FID-03).

### 7.2 SQL probes (XBOS DB — `xevn_xbos`)

```sql
-- REC-INT-SQL-10: member legal entities (Plane A count)
SELECT t.tenant_id, le.code, le.name
FROM xbos_tenant_registry t
JOIN xbos_legal_entity le
  ON le.tenant_id = t.tenant_id AND le.company_id = t.default_company_id
WHERE t.tenant_kind = 'member' AND t.status = 'active'
  AND le.status IS DISTINCT FROM 'deleted'
ORDER BY t.tenant_id;

-- REC-INT-SQL-11: holding legal row on master
SELECT code, name FROM xbos_legal_entity
WHERE tenant_id = 'xevn' AND company_id = 'holding' AND status <> 'deleted';
```
