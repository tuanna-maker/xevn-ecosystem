## 2. BR-EXEC-01 — No user-visible mock when API mode on

> **When HRM/portal runtime is in API data mode, every user-visible datum (table row, chart series, KPI, axis label, avatar strip, tenant/company name) MUST originate from a scoped API response or a deterministic empty/error state — never from static demo arrays, legacy `HRM_MOCK_*`, or silent fallback fiction.**

### 2.1 API mode predicate (machine-checkable)

| Predicate | True when | Code seam |
|-----------|-----------|-----------|
| **API-MODE-HRM** | `isHrmApiDataMode()` returns true | `apps/web/hrm/src/lib/hrmDataMode.ts` |
| **API-MODE-PORTAL** | Embed path `/hr/*` OR `hasPortalSession()` OR `getHrmPortalMode()` | same + portal auth bridge |
| **API-MODE-FLAG** | `VITE_HRM_USE_API` ≠ `'false'` AND NOT remote localhost Supabase misconfig | env + `isRemoteLocalhostSupabaseMisconfig()` |
| **MOCK-FALLBACK-OFF** | `VITE_ALLOW_MOCK_FALLBACK` ≠ `'true'` (production pilot default) | portal CC hooks |

**Composite:** `BR-EXEC-01 applies` ⇔ **API-MODE-HRM** OR **API-MODE-PORTAL** OR (**API-MODE-FLAG** AND **MOCK-FALLBACK-OFF**).

### 2.2 Rule matrix (extends BR-MOCK-01 / BR-MOCK-02)

| ID | Condition (when BR-EXEC-01 applies) | Required UI behavior | Forbidden |
|----|-------------------------------------|----------------------|-----------|
| BR-EXEC-01a | Primary list/aggregate API **200** + `data=[]` | Empty state with copy (BR-MOCK-01) | Render static `const data = [...]` demo rows/charts |
| BR-EXEC-01b | Primary API **4xx/5xx** / network / timeout | Error banner (`API_LOAD_FAILED_MESSAGE`) | `previewMockRows(HRM_MOCK_*)`, `MOCK_SEED`, `INFRASTRUCTURE_MOCK_SEED` |
| BR-EXEC-01c | Chart/KPI widget mounted | Network shows scoped API call **before** paint OR empty skeleton | Hardcoded tenant names (`1OFFICE`, `UNICOM`, `MISA`, `Trang Trí`, fictional branches) |
| BR-EXEC-01d | Label axis = company or department | Join from org-foundation / `departments` API (BR-DQ-01) | Slug code or demo company string as display label |
| BR-EXEC-01e | Secondary tab uses local-only state (work history, performance) | Wire to employee/tasks API OR hide tab with «Chưa kết nối API» | `initialWorkHistory`, `monthlyPerformanceData`, `radarChartData` constants shown as if live |
| BR-EXEC-01f | Dead mock constants in file but unused in render | Remove in W1 cleanup (dev-fe) | Leave grep FAIL noise for QA gate |
