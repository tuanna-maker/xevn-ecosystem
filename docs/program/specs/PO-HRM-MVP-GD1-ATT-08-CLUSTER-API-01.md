1. **AuthZ + U19 scope** — resolve company/slug như LIVE leave-requests family; OOS → `HRM-SCOPE-409` / 404 (không empty-mask).
2. **Validate range** — `end_date` ≥ `start_date` · leave_type ∈ EFF (else `HRM-LEAVE-TYPE-UNKNOWN`) · invalid → `HRM-VAL-400`.
3. **Holiday year set** — load thin year set for company/year spanning range; **ABSENT** → **CHẶN** preview/submit path with `HRM-LEAVE-HOL-MISSING` (or VAL-400) — **no** silent 2xx treat as empty holidays · **≠** claim ATT-03b DONE.

5. **Engine BR-BP-LV-05** — count **working days only**; exclude T7/CN/Lễ; gold **T6→T2 → working_days=2 · calendar_days=4**; if caller/UI would trừ **4** as quỹ → **FAIL AC** (reject soft-OK inflate on ALIGN).
