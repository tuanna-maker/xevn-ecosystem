## Explicit blocker and prerequisites

### Blocker

Corporate domain `portal.xe.vn` cannot be configured live because DNS is not publicly resolvable (NXDOMAIN). Without DNS A/AAAA record and zone control, TLS issuance/challenge cannot be completed.

### Missing prerequisites (exact)

1. **Domain/DNS ownership confirmation**
   - Owner: PM to coordinate with corporate IT/domain admin.
   - Need confirmation of who controls DNS zone for `xe.vn` (registrar/DNS provider account owner).
2. **Public DNS record creation**
   - Add `A` record: `portal.xe.vn -> 14.225.217.232`.
   - Optional `AAAA` if IPv6 endpoint is intended.
   - TTL recommendation: 300 during cutover.
3. **Certificate challenge permission**
   - Allow HTTP-01 challenge on port 80 for `portal.xe.vn` (or provide DNS-01 access/token if corporate policy blocks HTTP-01).
4. **Post-DNS propagation window**
   - Wait until `nslookup portal.xe.vn 8.8.8.8` returns `14.225.217.232`.

## Planned immediate actions after unblock (already prepared)

1. Update nginx `server_name portal.xe.vn`.
2. Issue cert (`certbot --nginx -d portal.xe.vn` or corporate cert import).
3. Reload nginx and verify HSTS.
