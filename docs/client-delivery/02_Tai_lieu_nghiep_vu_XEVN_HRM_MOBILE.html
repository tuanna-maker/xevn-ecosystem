1. Giới thiệu tài liệu

1.1 Mục đích. Mô tả yêu cầu chức năng và phi chức năng của ứng dụng HRM Mobile phục vụ lập trình, kiểm thử và nghiệm thu.

1.2 Phạm vi. Các module MOD-AUTH-MOB, MOD-ATT, MOD-LEV, MOD-REQ, MOD-MGR, MOD-PAY, MOD-NOTI, MOD-SET, MOD-OFF (khung). Chi tiết ID xem bản Markdown đầy đủ.

1.3 Tham chiếu. BRD 01_Tai_lieu_thiet_ke_he_thong_XEVN_HRM_MOBILE.md; HDSD HUONG_DAN_DANG_NHAP_PILOT.md.

2. Tổng quan hệ thống

Client Expo gọi REST HRM API; xác thực JWT; header x-tenant-id / x-company-id theo phạm vi sau đăng nhập.
